# MC621 - Desafios de Programação (Unicamp)

Laboratórios da disciplina MC621, cursada no Instituto de Computacao da Unicamp no 2 semestre de 2026, com foco em resolução de questões de maratonas e desenvolvimento de raciocínio de programação competitiva.

## Estrutura

Cada `placarX` representa um Contest composto por pastas (`problem1`, `problem2`, ...). Em cada pasta contém o código (geralmente) em C++ e o PDF do problema.
